# Simple Stardew Valley Keg Calculator
Input the needed number of Kegs, and out comes the total material numbers and cost, as well as one week's worth of money from that amount of Kegs (assumes you use either Ancient Fruit or Starfruit). I didn't know if anyone had already made this, but I couldn't find anything so I made a simple version myself. The project doesn't show the necessary number of Oak Resin, so just know that you'll need one resin per keg.
